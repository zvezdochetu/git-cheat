# Работа сооо стейджем

Если один или несколько файлов изменены, удалены или добавлены, можно добавить их на стейдж (Staging Area).

Добавление файла на стейдж:

```
git add <имя_файла>
```

Добавление всех измененных файлов на стейдж:

```
git add .
```

Удаление файла со стейджа:

```
git restore --staged <имя_файла>
```

Удаление всех файлов со стейджа:

```
git restore --staged .
```
